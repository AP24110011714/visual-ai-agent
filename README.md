# Visual AI Agent

A browser activity monitoring system that captures browsing activity, extracts text using OCR, analyzes user activity with AI, and displays insights through a modern dashboard.

---

## Features

- Browser Activity Tracking
- Screenshot Capture
- OCR Text Extraction
- AI-based Activity Analysis
- Activity Dashboard
- Search Activities
- Category Filter
- Productivity Filter
- Sort by Newest / Oldest
- Interactive Charts
- CSV Export
- Activity Details Popup

---

## Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Dashboard

```bash
cd dashboard
npm install
npm run dev
```

### Chrome Extension

1. Open Chrome
2. Go to chrome://extensions
3. Enable Developer Mode
4. Click Load Unpacked
5. Select the extension folder
